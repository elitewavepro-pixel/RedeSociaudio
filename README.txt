REDE SOCIAUDIO V20.2

NOVO: Chat Profissional com conversas individuais, mensagens, áudio, documentos e arquivos técnicos.

REDE SOCIAUDIO V19.3 — PLANOS E LIMITES DE VÍDEO

NOVIDADES:
- Plano Gratuito: vídeos de até 250 MB.
- Plano Profissional PRO: vídeos de até 2 GB.
- Plano Empresa: vídeos de até 5 GB.
- Administrador: vídeos de até 5 GB.
- O limite aparece automaticamente na caixa de publicação.
- Validação no navegador e no servidor.
- Painel administrativo para alterar o plano de cada usuário.
- Perfil mostra o plano atual e o limite por vídeo.
- Dados permanentes preservados em AppData\Local\RedeSociaudio.

COMO USAR:
1. Feche a versão anterior.
2. Execute INICIAR_REDE_SOCIAUDIO.bat.
3. Pressione Ctrl+F5 no navegador.
4. Abra Administração para configurar os planos.
5. Clique em Vídeo para ver o limite da conta.

IMPORTANTE:
A versão local ainda envia o vídeo pelo navegador para o servidor Python. Para arquivos de vários GB, a versão online deverá usar upload em partes e armazenamento em nuvem.
